OFFICIAL DOWNLOAD→LOCAL BUILD→PACMAN UPGRADE

A SMALL TOOL FOR A REPEATED JOB

Download once.
Let pacman handle
the installation.

Grok Bot ships Linux packages. This tool bridges those downloads to Arch: it checks the bundled version and architecture, generates a PKGBUILD, and builds your local package.

Start with the official Linux x64 RPM or DEB ↗. Run the updater as your normal user; administrator access is needed only for installation.

Download the updater release ↗
1

Prepare your build tools

sudo pacman -S --needed base-devel libarchive python git
2

Clone and inspect the source

git clone https://github.com/danimoya/grok-bot-arch.git
cd grok-bot-arch
less bin/grok-bot-update
3

Build and upgrade

python3 bin/grok-bot-update --install

Chooses the newest completed RPM or DEB in Downloads. Omit --install to build only. Restart the app after upgrading.

01 / INSPECTABLE

The recipe comes with it.

Your output includes the Arch package, its PKGBUILD, and build metadata with a source SHA-256. Equal and older versions are refused.
